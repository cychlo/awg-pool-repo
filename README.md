
# awg-pool + luci-app-awg-pool
awg peer's accessibility cheker

Failover пула AmneziaWG-интерфейсов OpenWrt 25.12.x с проверкой реальной
пропускной способности. Работает вместе с Forkop 2.0 (группа Fallback).

## Разделение обязанностей

| Задача | Кто |
|---|---|
| Обнаружить отказ, переключиться за секунды, вернуться на приоритет | Forkop Fallback |
| Отбраковать медленный, но живой сервер | демон awg-pool |
| Перебрать все страны пула | демон awg-pool |
| Не дать всем интерфейсам сесть на одну страну | демон awg-pool |

Демон **не изменяет** конфигурацию Forkop, поэтому ядро sing-box не
перезапускается и остальные секции не рвутся.

## Архитектура

Каждый интерфейс пула — отдельный клиентский ключ и свой Address.
Сервер держит одну сессию на ключ, поэтому одинаковые ключи запрещены
(демон проверяет это в preflight).

Число интерфейсов пула = число занятых слотов провайдера.
Пример: 3 AWG + 2 прокси = 5 слотов.

## Требования

- OpenWrt 25.12.x, `apk`
- `kmod-amneziawg`, `amneziawg-tools`, `luci-proto-amneziawg` (сторонний feed,
  должен совпадать с `uname -r`; в пакет НЕ входит)
- `curl`, `ca-bundle`, `ip-full`, `flock` — ставятся как зависимости
- Forkop 2.0 с группой Fallback над интерфейсами секции
