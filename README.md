# awg-pool + luci-app-awg-pool

Failover пула AmneziaWG-интерфейсов OpenWrt 25.12.x с проверкой реальной
пропускной способности. Работает вместе с Forkop 2.0 (группа Fallback).

Пакеты `noarch` (скрипт + JS): один и тот же `.apk` ставится на любые
архитектуры, в том числе `aarch64_cortex-a53` и `aarch64_generic`.

## Разделение обязанностей

| Задача | Кто |
|---|---|
| Обнаружить отказ, переключиться за секунды, вернуться на приоритет | Forkop Fallback |
| Отбраковать медленный, но живой сервер | демон awg-pool |
| Перебрать все страны пула | демон awg-pool |
| Не дать всем интерфейсам сесть на одну страну | демон awg-pool |

Демон **не изменяет** конфигурацию Forkop, поэтому ядро sing-box не
перезапускается и остальные секции не рвутся.

## Архитектура

Каждый интерфейс пула — отдельный клиентский ключ и свой Address.
Сервер держит одну сессию на ключ, поэтому одинаковые ключи запрещены
(демон проверяет это в preflight, как и совпадение стран).

Число интерфейсов пула = число занятых слотов провайдера.
Пример: 3 AWG + 2 прокси = 5 слотов. **Максимум интерфейсов в пуле — 8**
(ограничение числа проверочных правил маршрутизации).

Проверки каждого интерфейса идут через его own туннель: демон создаёт
отдельную таблицу маршрутизации и `ip rule` на интерфейс и удаляет их
при штатной остановке. Правила, оставшиеся после аварийного завершения
(SIGKILL, OOM), демон **снимает при следующем старте**: удаляются только
правила с его приоритетами (200..221) и его таблицами на интерфейсах пула,
чужая политика маршрутизации не затрагивается.

### Как отбраковывается медленный сервер

Health-проверка (HTTPS 200/204) идёт каждый цикл, замер скорости — раз в
`speed_every` циклов. Это **независимые счётчики**: `fail_threshold`
неудач health подряд или `speed_fail_threshold` неудачных замеров
скорости запускают перебор страны. Успешный health между замерами
счётчик скорости не сбрасывает.

Замер, который **не состоялся** (узел `speed_host` недоступен или
заблокирован, вернул HTTP-ошибку), неудачей не считается: счётчик не
растёт и страна не отбраковывается. Если при подборе страны health прошёл,
а замер не состоялся, страна принимается по health.

### Защита от ложного отказа

- `cross_check`: если не отвечает ни один интерфейс пула (включая
  резервы), перебор не запускается — вероятно, DPI заблокировал
  проверочные адреса, а не сервер.
- WAN проверяется **отдельными** адресами (`wan_urls`, по умолчанию
  captive-portal проверки по HTTP): блокировка DoH-адресов на голом WAN
  не останавливает демон. Отсутствие default-маршрута в таблице main
  считается отказом WAN (проверки пропускаются).
- `sweep_cooldown` — пауза между переборами; `dead_ttl` — cooldown
  отказавшей страны (`0` — без cooldown).
- Если перебор не нашёл годной страны, интерфейсу **возвращается прежняя**
  страна, а не остаётся последний проверенный нерабочий хост.

## Требования

- OpenWrt 25.12.x, `apk`
- `kmod-amneziawg`, `amneziawg-tools`, `luci-proto-amneziawg` (сторонний feed,
  должен совпадать с `uname -r`; в пакет НЕ входит)
- `curl`, `ca-bundle`, `ip-full` — ставятся как зависимости
  (`flock` — апплет busybox, отдельный пакет не нужен)
- Forkop 2.0 с группой Fallback над интерфейсами секции
- Именование peer-секций: `amneziawg_<iface>` (или `wireguard_<iface>`),
  ровно **один** peer на интерфейс пула, `route_allowed_ips=0`

## Установка

```sh
apk add --allow-untrusted ./awg-pool-*.apk ./luci-app-awg-pool-*.apk
```

После установки откройте **Службы → AWG Failover**, добавьте интерфейсы
пула (порядок = приоритет: первый — рабочий, остальные — резервы; порядок
меняется перетаскиванием строк) и страны (минимум две), нажмите
**Save & Apply** — служба перезапустится автоматически (procd-триггер
на конфиг `awg-failover`).

При обновлении пакета служба перезапускается, если пул настроен.

## Использование

```sh
awg-pool --status          # состояние пула, скорости, cooldown'ы
/etc/init.d/awg-pool start|stop|restart|enable|disable
awg-pool --daemon          # основной режим (запускается procd)
```

Разовые команды **работают только при остановленной службе**:

```sh
/etc/init.d/awg-pool stop
awg-pool --once            # одна проверка рабочего интерфейса
awg-pool --rotate awg1     # принудительно сменить страну интерфейса пула
/etc/init.d/awg-pool start
```

Если служба запущена, `--once` и `--rotate` ничего не делают, печатают
сообщение и завершаются с кодом **2** (демон держит блокировку).
`--rotate` всегда выбирает страну, отличную от текущей.

## Основные настройки (/etc/config/awg-failover)

| Опция | По умолчанию | Смысл |
|---|---|---|
| `check_interval` | 20 | период проверок, с |
| `fail_threshold` | 3 | неудач health подряд до перебора |
| `speed_fail_threshold` | 2 | неудачных замеров скорости до перебора |
| `speed_every` | 30 | замер скорости раз в N циклов (0 — только при подборе) |
| `min_speed_kbps` | 200 | порог скорости, КБ/с (200 ≈ 1.6 Мбит/с) |
| `health_urls` | DoH 8.8.8.8/8.8.4.4, 1.1.1.1 | проверка через туннель, только IP |
| `wan_urls` | captive-portal HTTP | проверка голого WAN |
| `tls_max` | 1.2 | потолок TLS: `1.2`, `1.3` или `auto` (DPI в РФ часто ломает 1.3) |
| `cross_check` | 1 | не перебирать, если молчит весь пул |
| `sweep_cooldown` | 90 | пауза между переборами, с |
| `dead_ttl` | 600 | cooldown отказавшей страны, с (0 — без cooldown) |
| `standby_every` | 15 | проверка резерва раз в N циклов (0 — выкл) |
| `max_tries` | 4 | стран за один перебор |

Значения — только целые числа (до 9 цифр; ведущие нули допускаются и
срезаются). Нижние границы: `check_interval` ≥ 5, `health_timeout`,
`health_tries`, `max_tries`, `fail_threshold`, `speed_fail_threshold` ≥ 1,
`speed_window` ≥ 2, `speed_bytes` ≥ 100000.

В секциях `server` поле `host` допускает только буквы, цифры и `. _ : -`,
`port` — число 1–65535; иначе страна пропускается с предупреждением в логе.

Резервы перебираются после **двух** неудач подряд, с cross-check и
отдельным cooldown на интерфейс. Правки конфигурации через `uci`
применяются после перезапуска службы (`reload_config`/Save & Apply делают
это автоматически).

## Удаление и откат

```sh
apk del luci-app-awg-pool awg-pool
/etc/awg-pool/restore.sh   # вернуть endpoint'ы к снимку до установки
rm -rf /etc/awg-pool /etc/config/awg-failover   # полная очистка
```

`restore.sh` снимает только проверочные правила интерфейсов пула;
чужие таблицы маршрутизации не затрагиваются. Секции, которых к моменту
отката уже нет, пропускаются.

Снимок endpoint'ов делается **один раз** при первой установке. Чтобы при
повторной установке снять его заново, выполните перед ней
`rm -rf /etc/awg-pool`.

## Ограничения

- Не более 8 интерфейсов в пуле.
- Демон меняет только `endpoint_host` и `endpoint_port`: у всех стран
  должны быть одинаковые публичный ключ сервера и параметры AWG.
- Каждая ротация делает `uci commit network` (запись во flash).
- Замер скорости использует `speed.cloudflare.com/__down` — произвольный
  хост подставлять нельзя.
- Каждый замер качает `speed_bytes` (по умолчанию 2 МБ) — учитывайте
  тарификацию трафика на мобильных каналах.
- Интерфейс LuCI только на русском языке.
