# Изменения 1.3.0 -> 1.3.1

Исправления по результатам аудита. Перепроектирование ротации (смена endpoint
без `uci commit`) в этот релиз НЕ входит.

## Сборка / пакеты
- `awg-pool/Makefile`, `luci-app-awg-pool/Makefile`: строки в блоках `install`
  начинаются с табуляции (были пробелы).
- `awg-pool/Makefile`: убрана лишняя зависимость `+flock` (апплет busybox);
  `postinst` делает `restart` (после обновления работал бы старый демон),
  аргументы `uci get` взяты в кавычки, убрано продолжение строки через `\`;
  `restore.sh` пропускает секции, которых больше нет.
- `luci-app-awg-pool/Makefile`: `postinst`/`prerm` вместо restart rpcd+uhttpd
  делают `killall -HUP rpcd` и чистят кэш LuCI (как штатный luci.mk).
- Версии пакетов и скрипта: 1.3.1.

## Демон (`awg-pool/files/awg-pool`)
- Старт: снимаются устаревшие проверочные правила/таблицы прошлых запусков
  (`probe_cleanup`), иначе после аварий кончались приоритеты/таблицы.
- `wan_ok`: нет default-маршрута в main -> WAN недоступен (раньше -> исправен).
- `speed`: третий исход (код 2) «замер не состоялся» (код 000, нет вывода,
  HTTP-ошибка). Не увеличивает `SFAILS`, не бракует страну при подборе.
- `rotate`: при неудаче всех кандидатов возвращается прежний endpoint
  (`rotate_restore`).
- `--rotate`: текущая страна всегда исключается из кандидатов.
- `--once`/`--rotate` при работающей службе завершаются кодом 2 с понятным
  сообщением (раньше молча код 0).
- `apply_host` -> `apply_endpoint`: host и port проверяются (`valid_host`,
  `valid_port`) до попадания в `uci batch` (перевод строки в port давал
  произвольную команду `set` от root).
- `load_config`: числа нормализуются (ведущие нули срезаются, не более 9 цифр),
  нижние границы для `health_tries`, `max_tries`, `speed_window`,
  `health_timeout`, `speed_bytes`; причина «пул не настроен» выводится в лог.
- `pick_probe`: таблица и приоритет выбираются независимо (повторный вызов
  больше не возвращает 0 без приоритета). `probe_ok`/`probe_up`:
  сопоставление правил с границей слова (`awg1` != `awg10`, `25` != `250`).
- `nap`: `sleep` запускается с закрытым дескриптором блокировки (`9>&-`).
- Главный цикл: убран бесполезный цикл `set_pr` (читал тот же кэш).

## LuCI (`main.js`)
- `form.NamedSection`: корректные аргументы `('main', 'settings', title, descr)`.
- Убран ручной `restart` + `reload()` из `handleSaveApply` (гонка с фиксацией
  конфига); перезапуск делает procd-триггер в init-скрипте.
- Секции `pool` и `server` — `form.TableSection` (перетаскивание `sortable`
  работает только там; порядок пула = приоритет).
- Проверка уникальности интерфейса в пуле и лимита 8 в форме.
- Из списка `tls_max` убраны TLS 1.0/1.1 (демон принимает их из UCI).
- Уточнены описания `dead_ttl=0` и несостоявшегося замера скорости.

## Init (`awg-pool.init`)
- `service_triggers` + `reload_service` (stop; start): применение конфига
  перезапускает демон.

## Тесты и CI
- `selftest.sh`: моки «нет default-маршрута» и «узел замера недоступен»,
  тесты на все пункты выше (всего добавлено ~25 проверок).
- `check.yml`: проверка табов в Makefile, `busybox sh` (синтаксис и selftest,
  пока не блокирующие), проверки согласованности под новую схему перезапуска.
- `build.yml`: проверка sha256 SDK, версия OpenWrt передаётся через `env`
  (без подстановки в shell), единая версия `actions/checkout`.

## Не менялось
`acl.json`, `menu.json`, `LICENSE`, `.gitignore`, `.gitattributes`.

## Известные ограничения (не исправлялись)
- Каждая ротация по-прежнему пишет `uci commit network` (отложено).
- Демон меняет только endpoint (одинаковые ключи/параметры у всех стран).
- Нет перевода интерфейса LuCI (только русский).
- Не проверено на устройстве: поведение ash на значениях вроде `08`
  (теперь значения нормализуются), поддержка `--tls-max 1.0/1.1` вашей сборкой curl.
